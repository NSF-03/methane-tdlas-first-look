# Data: Davis et al. (2023)

**Source.** N.M. Davis, D. Francis, J. Hodgkinson and R.P. Tatam (2023), data supporting the article
"Compact methane sensor using an integrating sphere and interband cascade laser at 3313 nm",
*Sensors and Actuators B: Chemical* 389, 133866, <https://doi.org/10.1016/j.snb.2023.133866>.
The data are published on Cranfield Online Research Data (CORD):
DOI [10.17862/cranfield.rd.22700626](https://doi.org/10.17862/cranfield.rd.22700626),
also listed at <https://dspace.lib.cranfield.ac.uk/handle/1826/22426>.

**Licence.** Creative Commons Attribution 4.0 International (CC BY 4.0),
<https://creativecommons.org/licenses/by/4.0/>. The data remain the work of the authors above.

**What is here.** Seven CSV files from that dataset, one per figure of the article
(Figures 5 to 11). They are unmodified copies; the only change is that the space in each
file name was replaced by an underscore (for example `Figure 5.csv` became `Figure_5.csv`).

| File | Contents (column headers as in the file) |
|---|---|
| `Figure_5.csv` | Raw detector signals: wavelength, 50 ppm methane in synthetic air, synthetic air |
| `Figure_6.csv` | Detected absorbance at 50 ppm and the HITRAN absorbance for 50 ppm |
| `Figure_7.csv` | Single-point absorbance against concentration, with errors |
| `Figure_8.csv` | Allan-Werle deviation against averaging time |
| `Figure_9.csv` | Detected absorbance, seven-Lorentzian fit and residual |
| `Figure_10.csv` | Ramp waveforms without and with vibration |
| `Figure_11.csv` | Residuals of the ramp waveforms without and with vibration |
